# 🚗 RentaCarExpress

## Descripción del proyecto

**RentaCarExpress** es un proyecto académico desarrollado en C# con Windows Forms y .NET 8 para el sistema operativo Windows.

El proyecto forma parte de la asignatura de Programación Básica.

## 🛠️ Tecnologías utilizadas

- **Lenguaje de programación:** C#
- **Framework:** .NET 8 (`net8.0-windows`)
- **Interfaz gráfica:** Windows Forms
- **Plataforma:** Windows

## ⚙️ Requisitos

Para abrir y ejecutar el proyecto necesitas:

- Windows.
- .NET 8 SDK.
- Visual Studio con la carga de trabajo de desarrollo de escritorio de .NET, o una herramienta compatible con proyectos .NET.

## ▶️ Cómo ejecutar el proyecto

1. Descarga o clona el repositorio.
2. Abre `RentaCarExpress.csproj` en Visual Studio.
3. Espera a que se restauren las dependencias.
4. Compila el proyecto.
5. Ejecuta la aplicación.

También puedes utilizar la terminal desde la carpeta del proyecto:

```bash
dotnet build
dotnet run
```
